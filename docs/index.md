# Rusk β

Rusk は競技プログラミング向けの言語です。作者自身にとっての書きやすさと、競技プログラミングで十分な実行速度を重視して開発しています。

!!! note "開発状況"
    C++20 を生成する最小プロトタイプを実装しています。整数の入出力と演算、共有・コピー・代入、条件分岐と while ループを試せます。配列や関数定義などはまだ未実装です。

## 設計の背景

思想や設計理由、検討中の案は、リポジトリの [設計ノート](https://github.com/shogo314/rusk_b_01/tree/main/design) に記録しています。設計ノートには未実装の機能や未確定の構文も含まれます。

利用者向けの説明は実装済みの機能を基本とし、設計案との違いが分かるように整備します。
