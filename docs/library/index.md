# 標準ライブラリ

最小プロトタイプの標準ライブラリは `lib/core.rusk` です。以下は実装済みです。

| API | 振る舞い |
|---|---|
| `Int` | 符号付き64ビット整数。四則演算・剰余・符号演算で独立した値を返す |
| `Bool` | `true` / `false`。出力は `Yes` / `No` |
| `Char` | ASCII の1文字 |
| `Str` | ASCII 文字列。現時点では文字列演算・添字は未実装 |
| `Vec<Int>` | 整数オブジェクトを共有して格納する可変長配列 |
| `Unit` | 戻り値を省略した関数、または `-> Unit` と書いた関数の結果の型 |
| `copy(x)` | `Int`, `Bool`, `Char`, `Str`, `Vec<Int>` の独立したコピー。文字列・配列は長さに比例、それ以外は定数時間 |
| `__assign__(a, b)` | 同じ型の `a` の中身に `b` をコピー。共有先の同一性を保つ |
| `__read__()` | `in` の指定型に応じて `Int`, `Str`, `Char` を読む |
| `__write__(x)` | 基本型を区切りや改行なしで出力。`Vec<Int>` は要素間に空白を入れ、末尾に改行は付けない |
| `read_line()` | 改行までを `Str` として読み、改行と末尾の CR を取り除く |

`Int` と `Str` の入力は空白区切りです。`Char` は先頭の空白を飛ばして1文字読みます。整数入力は符号を許し、トークン全体が整数であることを検査します。EOF、不正な入力、整数の範囲外、非ASCII文字の入力は実行時エラーです。

トークン入力は後続の区切り文字を消費しません。例えば整数の直後に `read_line()` を呼ぶと、同じ行の残りを先頭の空白も含めて読みます。直後が改行なら空文字列です。

`Int`, `Char`, `Str` は `== != < <= > >=`、`Bool` は `== !=` に対応します。比較は値を見て、独立した `Bool` を返します。`Str` の順序は辞書順です。

条件では `Bool` はその値、`Int` と `Char` はゼロ以外、`Str` は空でない場合を真とします。暗黙変換のための `__bool__` と比較の `__eq__`, `__ne__`, `__lt__`, `__le__`, `__gt__`, `__ge__` というフック名は暫定です。

## 配列の操作

| API | 振る舞いと計算量 |
|---|---|
| `len(a: Vec<Int>)` | 要素数を独立した `Int` で返す。定数時間 |
| `push_back(a: Vec<Int>, x: Int)` | `x` を共有して末尾に追加。償却定数時間 |
| `copy(a: Vec<Int>)` | 各要素をコピーした新しい配列。時間・追加メモリとも要素数に比例 |
| `__assign__(a: Vec<Int>, b: Vec<Int>)` | 外側の `a` を保ち、各要素を新しくコピーして置換。時間・追加メモリとも `b` の要素数に比例 |
| `__getitem__(a: Vec<Int>, i: Int)` | 範囲を検査して要素を共有。定数時間 |
| `__setitem__(a: Vec<Int>, i: Int, x: Int)` | 範囲を検査して格納先を `x` に結び直し、`x` を共有して返す。定数時間 |

配列の拡張後も、取得済みの要素への共有は有効です。空配列は条件で偽、それ以外は真になります。添字とコピーの例は [言語リファレンス](../reference/index.md) を参照してください。

`[x; n]` は `Int` の初期値を要素ごとにコピーして配列を作ります。時間・追加メモリとも要素数に比例します。`a.len()` や `a.push_back(x)` のようなメソッド形式も使えます。

`pop_back`、配列を一括して読む入力構文、イテレータ、探索、ソートなどは未実装です。
