# 標準ライブラリ

標準の型・関数の使い方と保証をまとめるためのページです。現在は実装済みの API はありません。

## API の記載方針

各 API には、使える型と引数、戻り値、使用例に加え、次の情報を記載します。

- 元の値を変更するか。
- 値を共有するか、コピーするか。
- 空の入力や範囲外などの扱い。
- 計算量と追加メモリ。

まず入出力と基本型から追加し、コンテナ・走査・アルゴリズムを実装に合わせて拡充します。検討中の名前や仕様は [ライブラリの設計ノート](https://github.com/shogo314/rusk_b_01/blob/main/design/library.md) にあります。
