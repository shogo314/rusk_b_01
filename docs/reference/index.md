# 言語リファレンス

ここでは現在動く最小プロトタイプを説明します。設計ノート全体を実装したものではありません。型名 `Int` などと真偽値 `true` / `false` の綴りは、プロトタイプでの暫定表記です。

## 変数と共有

文の末尾には `;` を書きます。`//` から行末まではコメントです。

```text
let a := 10;
let b := a;        // 同じオブジェクトを共有
let c := copy(a);  // 独立したオブジェクト

a = 20;           // オブジェクトの中身を更新。b も 20
wt a, b, c;       // 20 20 10

a := 30;          // a の指すオブジェクトを変更
wt a, b;          // 30 20
```

宣言は `let x: Int := 1;` のように型を書けます。`let x: Int;` も使えますが、`:=` による初期化前の読み取りはコンパイルエラーです。暗黙の型変換はありません。

`{ ... }` はブロック文です。内側の宣言は外側の同名変数を隠します。同じスコープでの重複宣言はエラーです。変数のスコープを抜けても、共有されているオブジェクトは生存します。

## 演算と評価順序

`+ - * / %`、単項の `+ -`、括弧、関数呼び出しが使えます。乗除算・剰余は加減算より優先します。

`Int` は符号付き64ビットです。オーバーフローとゼロ除算は実行時エラーになります。除算は負の無限大方向に丸めます。例：`-7 / 3` は `-3`、`-7 % 3` は `2` です。範囲外の整数リテラルはコンパイルエラーです。

代入は右結合で、更新先を共有する値を返します。`a = b = 0;` と `a := b := 0;` が使えます。`:=` の左辺には変数と添字アクセスを使えます。`=`, `+=`, `-=`, `*=`, `/=`, `%=` は左辺のオブジェクトを更新します。

オペランドと引数は左から右に一度ずつ評価します。先に評価した引数はその時点のオブジェクトを保持するため、後続の引数でそのオブジェクトを更新すると変更が見えます。後続の引数で変数を結び直しても、保持済みの引数の共有先は変わりません。

通常の算術演算は `__add__(a, b)` などの関数呼び出しに展開します。複合代入は対応する `__iadd__` などがあれば呼び、なければ算術演算と `__assign__` を組み合わせます。

!!! note "まだ制限していない構文"
    代入を式に埋め込む場合の括弧の必須化と、一時オブジェクトへの代入の制限は未実装です。現在のパーサーが受け付ける範囲を、最終仕様とは扱いません。

## 入出力

```text
in a, b: Int;
in s: Str;
wt a + b, s;
```

`in` は変数を宣言し、型に応じた `__read__` を呼びます。`wt x, y;` は値の間に空白を一つ入れ、最後に改行します。`wt;` は改行のみです。

`Str` リテラルは `"abc"`、`Char` は `'a'` と書き、ASCII に限定します。文字列のエスケープは JSON 形式です。`Char` は `\n`, `\r`, `\t`, `\0`, `\\`, `\'`, `\"` に対応します。

実行時エラーは標準エラー出力に呼び出し元のファイル名・行・列を表示し、終了コード1で終了します。

## 条件分岐とループ

```text
in n: Int;
let i := 0;
let total := 0;
while i < n {
    in x: Int;
    i += 1;
    if x < 0 { continue; }
    total += x;
}
wt total;
```

この例は負の入力を飛ばし、非負の値だけを合計します。

`if 条件 { ... } else { ... }` は文として使えます。`else` は省略可能です。現在は `else if` の短縮構文に対応せず、`else { if ... }` と書きます。条件には基本型の暗黙の真偽変換を使います。

`while 条件 { ... }` は毎回条件を評価します。`loop { ... }` は無限ループです。`break;` と `continue;` は最も内側のループに作用し、ループの外で使うとコンパイルエラーです。

```text
while condition {
    // 本体
} else {
    // 条件が偽になって終了したときだけ実行
}
```

`while` の `else` は `break` で終了した場合は実行しません。初めから条件が偽なら実行します。内側のループの `break` は外側の `else` を妨げません。

初期化の解析は保守的です。`if` の両分岐で初期化した変数は後で読めますが、ループ本体や `while` の `else` だけで初期化した変数は、後では未初期化として扱います。定数条件や `break` による到達可能性は解析していません。

比較は加減算より優先順位が低く、代入より高くなります。比較の連鎖、短絡論理演算、`if` 式、`do while`、`for`、ループラベルはまだ実装していません。連鎖比較は誤って別の意味で受け付けないよう、現在は構文エラーにします。

## 整数配列

最初の配列型として `Vec<Int>` を使えます。型名には空白を挟んで `Vec< Int >` と書いても構いません。一般のジェネリクスや他の要素型、多次元配列はまだ未実装です。

```text
let x := 1;
let a: Vec<Int> := [x, 2, 3];
let held := a[0];
a[0] = 10;       // x と held も 10

a[0] := 20;      // 配列の格納先だけを結び直す
wt a;            // 20 2 3
wt x, held;      // 10 10

push_back(a, x); // x を共有して末尾に追加
wt len(a);       // 4
wt a[-1];        // 10
```

`[x, y]` は要素をコピーせず共有します。各要素を左から右に一度ずつ評価します。非空のリテラルは `let a := [1, 2];` と型注釈を省略できます。現在は全要素が `Int` であることを要求します。

空配列には型の手がかりが必要です。`let a: Vec<Int> := [];`、既存の `a` に対する `a := [];` と `a = [];` が使えます。関数の引数も、残った候補すべてが同じ引数型を要求する場合にはその型を使います。例えば `len([])` は使えますが、`copy([])` は型を特定できません。`let a := [];` もエラーです。

添字は `Int` で、0始まりです。負数は末尾から数え、`-1` は末尾、`-len(a)` は先頭です。範囲外は実行時エラーです。長さが0なら有効な添字はありません。読み取り・更新・結び直しのすべてで検査します。

- `a[i]` は要素オブジェクトを共有して返します。
- `a[i] = x` は取得したオブジェクトの中身を更新します。
- `a[i] := x` は配列の格納先を `x` に結び直し、そのオブジェクトを返します。以前取得した要素への共有は古いオブジェクトを指し続けます。
- `a[i] += x` は要素を取得してから右辺を評価し、取得済みのオブジェクトを更新します。

添字アクセスは `__getitem__`、添字への `:=` は `__setitem__` に展開します。後者では配列、添字、右辺の順にオブジェクトを保持してから関数を呼びます。通常の関数引数と同様、右辺が先に保持したオブジェクトを更新した場合は、その更新が呼び出しに反映されます。`=` と複合代入では右辺より先に要素自体を取得します。いずれも式を重複評価しません。

`copy(a)` は外側と各要素を新しく作ります。`a = b` も各要素をコピーしますが、外側の `a` の同一性は保ちます。以前取得した `a` の要素は更新しません。`a = a` でも同じく要素をコピーし直します。`Int` 配列のみなので、より深い構造の再帰コピーは今後の実装対象です。

`if a { ... }` は配列が空なら偽、それ以外は真です。`wt a;` は要素を空白区切りで出力し、最後に改行します。空配列なら改行だけです。配列の比較、連結、スライスはまだ使えません。

## 繰り返し初期化

```text
let counts := [0; 4];
counts[1] += 1;
wt counts;  // 0 1 0 0
```

`[x; n]` は、初期値 `x`、個数 `n` の順にそれぞれ一度だけ評価してから、各要素に独立したコピーを作ります。現在は初期値と個数の両方が `Int` の場合だけ使えます。型注釈なしでも結果は `Vec<Int>` です。

```text
let x := 7;
let a := [x; 3];
a[0] = 10;
x = 8;
wt a;  // 10 7 7
```

個数0は空配列です。この場合も初期値の式を評価します。個数が負、または配列の格納形式で表せる長さを超える場合は、位置付きの実行時エラーです。実際に確保できるメモリ量は実行環境に依存します。

## メソッド形式

`a.f(x, y)` は `f(a, x, y)` と同じ関数呼び出しです。メソッド専用の定義や探索規則はありません。

```text
let a := [1, 2];
a.push_back(3);
wt a.len();        // 3
wt a.copy()[0];    // 1
wt a[0].copy();    // 1
```

受け手の式を先に一度だけ評価し、その後に引数を左から右へ評価します。受け手も通常の引数と同じ共有ルールです。メソッド形式と添字は連続して書けます。フィールドアクセスはまだ実装していないため、ドットの後には関数名と丸括弧が必要です。

## 関数定義

トップレベルに `fn` で関数を定義できます。引数型は明示します。戻り型を省略すると `Unit` で、値を返す関数には `-> 型` が必要です。戻り型の推論はまだ行いません。

```text
fn gcd(a: Int, b: Int) -> Int {
    while b {
        let r := a % b;
        a := b;
        b := r;
    }
    return a;
}
wt gcd(48, 18);  // 6
```

`return x;` は `x` のオブジェクトをコピーせず共有して返します。引数の受け渡しも共有です。引数への `=` は呼び出し元と共有しているオブジェクトを更新し、引数への `:=` は関数内の変数だけを結び直します。

```text
fn update(x: Int) { x = 5; }
fn first(a: Vec<Int>) -> Int { return a[0]; }

let x := 1;
update(x);
wt x;  // 5

let a := [1, 2];
first(a) = 9;
wt a;  // 9 2
```

関数内で作った値も返せます。ローカル変数のスコープが終わっても、返したオブジェクトは生存します。独立した値を返すには明示的に `copy` を使います。戻り型が `Vec<Int>` の関数では `return [];` と書けます。

`Unit` の関数は末尾まで進むか、`return;` で終了します。別の `Unit` 関数の呼び出しを `return other();` と返すこともできます。トップレベルの `return` はエラーです。

関数はソース内の定義順に関係なく呼べます。再帰と相互再帰が使えます。同名関数は引数型の完全一致で選び、メソッド形式でも同じ規則です。同じ名前と引数型の重複定義はエラーで、戻り型だけを変えたオーバーロードは入力用の `__read__` を除いてできません。

現在の関数が参照できるのは、その引数・ローカル変数と、トップレベルの型・関数です。トップレベルの実行文で宣言した変数は関数から参照できません。ローカル関数と外部変数の捕捉、ジェネリクス、名前付き引数、デフォルト引数、関数を値として渡す機能はまだありません。

値を返す関数は、末尾まで進んで値を返さない可能性があるとコンパイルエラーになります。現状の検査では `return`、ブロック内の順序、`if` の両分岐を見ます。定数条件やループが必ず戻ることは証明しないため、ループだけで必ず戻るように書いた場合も、必要に応じて末尾に `return` を置きます。

関数本体は未使用でも検査します。引数名の重複、同じスコープでの再宣言、戻り型の不一致、初期化前の読み取りもエラーです。早期に `return` する分岐は、後続の文に到達する分岐の初期化状態と区別します。実行時エラーの位置は、関数内で失敗した演算の位置です。呼び出し履歴の表示は未実装です。
