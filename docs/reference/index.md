# 言語リファレンス

実装された構文と、その正確な振る舞いをまとめるためのページです。現在はコンパイラ未実装のため、仕様の本文はまだ掲載していません。

## 今後説明する領域

| 領域 | 主な内容 |
|---|---|
| 値と変数 | 宣言、共有、コピー、代入、スコープ |
| 型 | 基本型、読み取り制限、ユーザー定義型 |
| 式 | 関数呼び出し、演算子、添字、ブロック式 |
| 制御構文 | 条件分岐、ループ、分解、パターンマッチ |
| 関数 | 引数、戻り値、ジェネリクス |
| プログラムの構成 | トップレベルの処理、別ファイルの読み込み |
| エラー | コンパイル時の診断、実行時エラー |

説明を追加するときは、構文例、実行結果、制約とエラーになる場合を示します。設計理由や未決定の選択肢は [設計ノート](https://github.com/shogo314/rusk_b_01/tree/main/design) で扱います。
