# 開発ガイド

Rusk β は Rust と Parol を使って実装する方針です。コンパイラのコードはまだなく、最初に実装する機能の範囲を検討しています。

## 記録を分ける

| 記録 | 内容 |
|---|---|
| `design/` | 設計の思想・理由・合意・候補・保留事項 |
| `docs/` | 実装済み機能の利用方法と仕様、開発手順 |
| ソースコードとテスト | 実際の振る舞いと検証 |

合意した設計、初期実装の範囲、実装上の暫定判断を区別します。未確定の設計を、実装済みの仕様として掲載しないようにします。

## 実装後に追加する内容

- ビルド・テスト・実行コマンド。
- 字句解析・構文解析・型検査・コード生成の構成。
- 機能を追加するときの変更箇所と検証方法。

ドキュメントの編集手順は [ドキュメントの編集と公開](documentation.md) にまとめています。
