# はじめに

Rusk β の導入から、プログラムの実行までを説明するページです。

現時点ではコンパイラの実装・配布はありません。インストール手順や実行コマンドは、利用できるようになった段階で追加します。

## 今後追加する内容

1. 必要な環境とインストール方法。
2. 最初のプログラムの作成と実行。
3. 整数や配列を読み、答えを出力する方法。
4. 競技プログラミングサイトへの提出方法。

設計中の書き方は [設計ノート](https://github.com/shogo314/rusk_b_01/tree/main/design) を参照してください。実行できるサンプルは、コンパイラの実装後に掲載します。
