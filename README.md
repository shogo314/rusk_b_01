# Rusk β

競技プログラミング向け言語 **Rusk のβ版**を開発・管理するリポジトリです。

作者自身にとっての書きやすさと、競技プログラミングで十分な実行速度を重視しています。Python と C++ に慣れた使い方を出発点に、言語を設計しています。

## 現在の状態

言語の思想・設計方針を整理している段階です。コンパイラの実装はまだありません。Rust と Parol を使って実装を進める方針です。

実装に合わせて細部を決めていくため、設計ノートには合意した方針と、検討中・保留中の案が含まれます。最初に実装する機能の範囲は未確定です。

## 設計ノート

[design/README.md](design/README.md) を入口として、思想、値の共有とコピー、型、構文、関数、標準ライブラリなどの記録をまとめています。

設計ノートは設計の判断基準や理由を残すもので、実装済みの機能を説明する言語ドキュメントとは区別します。

## ドキュメントの方針

利用者向けドキュメントは、他の人にも理解できる内容を目指し、実装済みの機能に合わせて整備します。MkDocs で構築し、GitHub Pages で公開する予定です。サイトの設定と公開はまだ行っていません。
